Используй скилл test-case-generator.

Аргументы: {{args}}
Первый аргумент — раздел/подпапка внутри test-cases/, остальное — источники (файлы требований, скриншоты, текст).

Порядок:
1. Прочитай источники и `test-cases/<раздел>/` (существующие кейсы и нумерацию).
2. Выведи список кейсов, которые собираешься создать: ID, название, тип, приоритет, техника тест-дизайна. Отдельно — раздел «Чего нет в требованиях» (до 5 рисков, которые документация не покрывает) с вопросами к аналитику.
3. Создай файлы по шаблону скилла.
4. В конце — список созданных файлов и открытые вопросы.
